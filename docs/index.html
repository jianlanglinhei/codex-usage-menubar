GOOD TO KNOW

以后怎么更新？How do I update the app?

在 App 设置或菜单栏右键菜单中选择「检查更新…」，下载完成后点击安装并重启。也可开启自动检查；不会自动安装。v1.0.4 及更早的用户需要先手动安装一次新版。Choose “Check for Updates…” in settings or the menu bar’s right-click menu, then install and relaunch. Automatic checks are optional; installation remains your choice. Versions 1.0.4 and earlier need one manual upgrade first.

杯子里的水量是真实额度吗？Is the fill level real usage data?

App 里的液位来自本机已登录 Codex 的额度数据，百分比与菜单栏同步；网页上方是自动播放的演示。应用图标是固定的约八成液位插画。The app’s fill level comes from your signed-in Codex account and matches the menu bar percentage. This webpage uses simulated data. The app icon is a fixed illustration at about 81%.

重置预测是官方承诺吗？Are reset forecasts official?

不是。预测来自第三方 Codex Reset Monitor，仅供参考，不能保证实际重置时间。你自己的额度重置倒计时来自 Codex 的额度窗口。No. Third-party forecasts from Codex Reset Monitor are estimates, not guarantees. Your personal reset countdown comes from Codex account limits.

支持哪些 Mac？Which Macs are supported?

当前下载包适用于 Apple 芯片 Mac（M 系列），需要 macOS 13 或更新版本。暂未提供 Intel 安装包。The download supports Apple Silicon Macs (M series) on macOS 13 or later. No Intel package is available.

有 Windows 版吗？Is a Windows version planned?

Windows 版考虑中，暂未确定发布时间。A Windows version is under consideration. No release date has been set.

为什么打开后没有额度？Why don’t I see my limits?

先确认本机已安装并登录 Codex CLI，再点击 App 右上角刷新。缺少 CLI、读取失败或数据过期时，App 会显示相应提示。Check that the Codex CLI is installed and signed in, then click Refresh. The app reports a missing CLI, failed reads or stale data.

这是 OpenAI 官方应用吗？Is this an official OpenAI app?

Codex Cub 是独立的 macOS 小工具，与 OpenAI 无隶属关系。额度由本地 Codex 提供，第三方预测会标注来源。Codex Cub is an independent macOS utility, not affiliated with OpenAI. Limits come from local Codex; third-party forecasts are labeled with their source.
